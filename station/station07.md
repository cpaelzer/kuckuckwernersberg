# 7. Sandsteintreppe

## Fuchs: “Schon gewusst?”

Der Erhalt von Wanderwegen ist eine wichtige Aufgabe. Einer der Arbeitsschritte heißt 'Schieben' von Wegen, dabei wird der Weg von losem Material und Bewuchs befreit. Schotter spielt eine wichtige Rolle bei der Drainage von Wegen, indem er das Wasser ableitet und so den Weg vor Erosion schützt. Dennoch kann es Probleme geben, wie das Ausschwemmen von Material und die Ablagerung von Schwemmmaterial. Deshalb ist regelmäßige Pflege unbedingt notwendig!
Doch so wichtig dies für die Waldwirtschaftliche Nutzung ist, dem Wanderer kommt eine verwunschene Sandsteintreppe wie hier deutlich schöner vor.
